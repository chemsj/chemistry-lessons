# 고체 결정 구조 살펴보기 — 원본은 여기가 아니다

이 폴더의 `index.html`은 **화학수행평가패키지에서 만들어 복사해 온 것**이다.
COD(Crystallography Open Database) 실측 결정 11종을 JSmol로 띄우는 자체완결 한 파일.

## 🔴 여기서 직접 고치지 않는다

고치면 다음 배포 때 **덮어써져 사라진다.** 고칠 일이 생기면:

```bash
# 화학수행평가패키지 폴더에서
vi 4_도구/build-crystal-hub.py          # 물질·버튼·설명을 여기서 고치고
bash 4_도구/deploy-crystal-hub.sh       # 두 주소에 함께 배포된다
```

## 같은 화면이 사는 두 주소

| 주소 | 쓰는 자리 |
|---|---|
| <https://chemsj.github.io/crystal-hub/> | **수업 중 전자칠판**에 치는 짧은 주소. 인쇄물·클래스룸 게시문이 이 주소를 쓴다 |
| <https://chemsj.github.io/chemistry-lessons/me-1-states/04-crystal-structures/> | **여기.** 학생이 나중에 단원에서 찾아 들어오는 자리 |

배포 스크립트가 두 곳을 함께 갱신한다. 한쪽만 손으로 고치면 갈라진다.

- 원본 파일: `…/Project_화학수행평가패키지/2_수업과평가/물질과에너지/1_물질의세가지상태/3_교사용/08차시-결정화면-허브.html`
- 첫 배포: 2026-09-01 (물질과 에너지 Ⅰ-8 고체의 분류 차시)
- COD 데이터는 퍼블릭 도메인(CC0)
